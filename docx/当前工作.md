- **落地配置**：
  为 PowerShell 7 与 Windows PowerShell 5.1 创建并配置全局 `$PROFILE`，在启动时自动执行 `Remove-Module PSReadLine`，平滑回退至系统原生经典控制台输入模式，彻底消除中文重复与菱形未知符号，日常命令补全与中文交互 100% 正常。

  1. **虚假 VT 状态回报**：`KxBase\console.c` 中 `Ext_SetConsoleMode` 在 Win7 原生报错 `ERROR_INVALID_PARAMETER` 时，剥离 `0x4`（`ENABLE_VIRTUAL_TERMINAL_PROCESSING`）后重试并直接向调用方返回 `TRUE`；`Ext_GetConsoleMode` 回读伪造 `0x4`，导致 PowerShell 与 PSReadLine 均误判控制台支持 VT 虚拟终端，激活 `VirtualTerminal` 模式发送转义序列。

  1. `KxBase\console.c` 优化句柄判定：当句柄无显式配置且属于控制台输出句柄时，自动继承活动屏幕缓冲区的 VT 状态，使 ANSI 模拟器正常截获转义码转为 Win32 控制台属性着色。
  2. 引入 `VXKEX_NO_CONSOLE_VT=1` 环境变量应急开关：置 1 时完全禁用 VT 模拟，原生穿透抛出 `ERROR_INVALID_PARAMETER`，强制调用方（PSReadLine/pwsh）自然平滑降级至成熟稳定的 `LegacyWin32Console` Win32 控制台 API 模式。
  3. 执行 `build-installer.cmd` 全量构建 Release x64 与 Win32 产物并打包生成 `KexSetup_Release.exe`。
